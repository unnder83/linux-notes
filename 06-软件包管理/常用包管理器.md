# 常用包管理器

## 发行版对应关系

| 发行版 | 包管理器 | 安装命令 |
| --- | --- | --- |
| Debian/Ubuntu | apt | `sudo apt install 包名` |
| CentOS/RHEL 7 | yum | `sudo yum install 包名` |
| Fedora/RHEL 8+ | dnf | `sudo dnf install 包名` |
| Arch | pacman | `sudo pacman -S 包名` |
| openSUSE | zypper | `sudo zypper install 包名` |

## apt 常用操作

```bash
sudo apt update              # 更新软件源索引
sudo apt upgrade             # 升级已安装的软件
sudo apt install nginx       # 安装
sudo apt remove nginx        # 卸载（保留配置）
sudo apt purge nginx         # 卸载并删除配置
apt search nginx             # 搜索
apt list --installed         # 已安装列表
```
