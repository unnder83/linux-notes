# Shell 脚本基础语法

## 脚本模板

```bash
#!/bin/bash
set -euo pipefail   # 出错退出、未定义变量报错、管道错误不忽略

name=$1             # 第一个参数
echo "Hello, ${name:-world}"
```

## 变量

```bash
a=1                 # 赋值等号两边不能有空格
echo "$a"           # 引用变量加引号更安全
echo "${a}"         # 推荐写法，便于拼接
```

## 条件判断

```bash
if [ -f /etc/passwd ]; then
  echo "文件存在"
elif [ -d /etc ]; then
  echo "目录存在"
else
  echo "都不存在"
fi
```

常用判断：`-f` 文件、`-d` 目录、`-z` 字符串为空、`-n` 非空、`-eq` 数值相等

## 循环

```bash
for f in *.md; do
  echo "处理: $f"
done

while read -r line; do
  echo "$line"
done < list.txt
```
