## crontab:定时任务

```bash
crontab -e    # 编辑（进入编辑器）
crontab -l    # 查看
```

### 格式（5 个时间字段 + 命令）

```html
分 时 日 月 周   命令
*  *  *  *  *   command

*/5 * * * *   每 5 分钟
0   3 * * *   每天凌晨 3 点
0   0 * * 1   每周一 0 点
@reboot       开机时执行
```



## at定时任务

at的守护进程atd会以后台模式运行，默认60秒检查一次job队列，使用`ps -ef | grep atd`查看进程是否存活。

at命令是一次性定时任务，执行完成既结束。

```bash
at [选项] [时间] #新建作业任务  Ctrl+D 结束at命令输入
atq #查询等待作业
atrm #删除指定作业
```

### at常用参数

| 参数       | 作用                                     | 示例                             |
|:---------- | ---------------------------------------- | -------------------------------- |
| `-V`       | 显示版本号                               | `at -V`                          |
| `-q queue` | 指定队列，默认 `at` 是 `a` 队列          | `at -q a now + 1 hour`           |
| `-f file`  | 从文件读取要执行的命令，脚本里最常用     | `at -f /home/user/task.sh 23:00` |
| `-m`       | 任务完成后给用户发邮件，即使没有输出也发 | `at -m now + 5 minutes`          |
| `-l`       | 列出待执行任务，等同于 `atq`             | `at -l`                          |
| `-d`       | 删除任务，等同于 `atrm`                  | `at -d 3`                        |
| `-c job`   | 查看某个任务的详细内容                   | `at -c 3`                        |
| `-v`       | 显示任务将被执行的时间                   | `at -v now + 1 minute`           |
| `-t time`  | 用精确格式指定时间                       | `at -t 202609211530`             |
| `-b`       | 相当于 `batch`，系统负载低时执行         | `at -b`                          |

### 坑点

- ⚠️ **crontab 的 PATH 的登录 shell 不一样**！cron 环境很干净（通常只有 `/usr/bin:/bin`）你平时能跑的脚本进了 cron 可能"找不到命令"。**所以 cron 里一律用绝对路径**（`/usr/bin/date` 而不是 `date`）
- ⚠️ **crontab 语法错一个就静默不执行**，不会报错——所以上线前要测试，并验证它真的在跑（看输出日志）
- ⚠️ `crontab -r` 会**清你所有定时任务**（且无确认），慎用
