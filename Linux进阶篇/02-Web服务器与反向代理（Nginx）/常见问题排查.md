# Nginx 常见问题排查

## 学习目标

- [ ] 掌握看错误日志定位问题的方法
- [ ] 能处理 403、404、502、504 等常见状态码
- [ ] 会排查端口占用、配置未生效等问题

## 状态码速查

| 状态码 | 常见原因 |
| --- | --- |
| 403 | 权限不足、目录索引未开 |
| 404 | 路径不对、root/alias 配置错 |
| 502 | 后端服务挂了、SELinux 拦截 |
| 504 | 后端超时、upstream 响应慢 |

## 排查命令

```bash
tail -f /var/log/nginx/error.log
tail -f /var/log/nginx/access.log
nginx -t
ss -tlnp | grep nginx
```
