## 面试速查（初级运维必答）

- Nginx 有哪些常用模块/发行版本？编译安装 vs yum 安装区别？
- 反向代理和正向代理、负载均衡的区别？负载均衡有哪些策略？
- 什么是动静分离？怎么配？为什么快？
- 怎么实现 Nginx 高可用？（keepalived + VIP）
- 反向代理后怎么拿到客户端真实 IP？（X-Forwarded-For / proxy_set_header）
- 浏览器缓存（强缓存/协商缓存）和 Nginx 缓存怎么配合？
- gzip 和 Brotli 区别？gzip_static 有什么用？
- 怎么限流？（limit_req / limit_conn / 漏桶、令牌桶）
- 日志如何切割？如何输出 JSON 方便对接 ELK？
- upstream 超时与重试怎么配？
