# 网络排障思路

## 学习目标

- [ ] 掌握从底层到上层的逐层排查方法
- [ ] 知道每一层该用什么工具
- [ ] 能独立定位常见网络故障

## 排查顺序

```
网卡是否正常 → IP 是否正确 → 网关能否 ping 通 → DNS 能否解析 → 端口是否监听 → 服务是否响应
```

| 层级 | 排查命令 |
| --- | --- |
| 网卡 | `ip link`、`ethtool` |
| IP/路由 | `ip addr`、`ip route` |
| 连通性 | `ping`、`traceroute` |
| DNS | `dig`、`nslookup` |
| 端口 | `ss -tlnp` |
| 应用 | `curl -v`、`telnet`、`nc` |
