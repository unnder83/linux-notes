# 网络配置深入

## 学习目标

- [ ] 掌握 ip 命令替代 ifconfig/route 的用法
- [ ] 理解网卡配置文件（CentOS/Ubuntu 两种风格）
- [ ] 掌握静态 IP、网关、DNS 的配置方法
- [ ] 了解多网卡、网卡绑定（bond）场景

## 命令对照表

| 旧命令 | 新命令 |
| --- | --- |
| `ifconfig` | `ip addr` |
| `route -n` | `ip route` |
| `netstat` | `ss` |
| `arp -a` | `ip neigh` |

## 配置文件位置

- CentOS/RHEL：`/etc/sysconfig/network-scripts/ifcfg-xxx`
- Ubuntu：`/etc/netplan/*.yaml`
- 通用：`/etc/hosts`、`/etc/resolv.conf`
