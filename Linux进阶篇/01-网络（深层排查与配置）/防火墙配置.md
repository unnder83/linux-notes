## firewalld 常用命令

```bash
systemctl status firewalld           # 查看状态
firewall-cmd --list-all              # 查看当前规则
firewall-cmd --add-port=80/tcp --permanent
firewall-cmd --add-service=http --permanent
firewall-cmd --reload                # 重载生效
```
