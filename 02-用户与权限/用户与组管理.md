# 用户与组管理

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `useradd` | 创建用户，`-m` 同时创建家目录 |
| `passwd` | 设置/修改密码 |
| `usermod` | 修改用户，`-aG` 追加附加组 |
| `userdel` | 删除用户，`-r` 同时删除家目录 |
| `groupadd` | 创建用户组 |
| `id` | 查看用户 UID/GID 和所属组 |
| `whoami` | 当前用户名 |

## 权限

```bash
chmod 755 file      # rwxr-xr-x
chmod u+x script.sh # 给属主加执行权限
chown user:group f  # 修改属主和属组
```

- 数字权限：r=4，w=2，x=1，三组分别对应 属主/属组/其他人
- `sudo` 临时提权，`su - user` 切换用户
