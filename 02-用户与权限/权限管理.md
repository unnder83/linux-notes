### `ls -l` 第一列

```
  -rw-r--r--  1 unnder unnder  12 Aug 13 10:00 a.txt
└┬┘└──┬──┘   └┬┘ └┬─┘  └─┬─┘
 类型  权限   链接 属主    属组
```

**数字模式**：`r=4, w=2, x=1`，三段相加：

```
rw-r--r--  →  4+2+0  4+0+0  4+0+0  →  644   ← 文件最常见权限
rwxr-xr-x  →  4+2+1  4+0+1  4+0+1  →  755   ← 目录/脚本最常见权限
rwxrwxrwx  →  777                           ← 安全红线！
```

### 关键命令

```bash
chmod 755 file                  # 数字模式：一次性设三段
chmod u+x file                  # 符号模式：给属主加执行（u=owner, g=group, o=other, a=all）
chmod g-w,o= file               # 组去掉写，其他人清空
chown zhangsan file             # 改属主
chown -R zhangsan /home/file    # 将目录下面文件全部改属主
chown zhangsan:dev file         # 同时改属主+属组
chgrp dev file                  # 只改组
```
