# Linux 学习笔记

用 [MarkText](https://marktext.app) 编辑的 Linux 学习笔记，使用 Git 进行版本管理，托管在 GitHub。

## 目录

- [01 基础命令](01-基础命令/)
- [02 用户与权限](02-用户与权限/)
- [03 进程管理](03-进程管理/)
- [04 网络配置](04-网络配置/)
- [05 Shell 脚本](05-Shell脚本/)
- [06 软件包管理](06-软件包管理/)

## 使用方式

1. 用 MarkText 打开本文件夹作为工作区
2. 新建笔记写入对应分类目录，文件名用中文描述内容
3. 写完后提交并推送：

```bash
git add .
git commit -m "笔记: 新增 xxx"
git push
```
