## 使用方式

1. 用 MarkText 打开本文件夹作为工作区
2. 新建笔记写入对应分类目录，文件名用中文描述内容
3. 写完后提交并推送：

```bash
git add .
git commit -m "笔记: 新增 xxx"
git push
```
