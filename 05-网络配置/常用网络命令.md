# 常用网络命令

## 排查思路

1. `ip addr` 看本机网卡和 IP
2. `ping` 测连通性
3. `ss -tlnp` 看端口监听
4. `curl` / `wget` 测服务响应

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `ip addr` | 查看/配置网卡（替代 ifconfig） |
| `ping host` | 测试连通性 |
| `ss -tlnp` | 查看 TCP 监听端口及进程（替代 netstat） |
| `curl -I url` | 只取响应头 |
| `wget url` | 下载文件 |
| `dig domain` / `nslookup` | DNS 解析查询 |
| `traceroute host` | 路由追踪 |

## 示例

```bash
ip addr show eth0
ss -tlnp | grep 8080
curl -v https://example.com
```
