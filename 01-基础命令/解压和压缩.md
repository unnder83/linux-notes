# 解压和压缩

## 常用命令

| 命令     | 说明           | 常用参数                                             |
| -------- | -------------- | ---------------------------------------------------- |
| `gzip`   | 压缩文件       |                                                      |
| `gunzip` | 解压文件       |                                                      |
| `zip`    | 压缩文件或目录 | `-r`递归压缩目录                                     |
| `unzip`  | 解压文件       | `-d<目录>`指定目录解压                               |
| `tar`    | 打包指令       | `-czvf`压缩、`-tzvf`查看、`-xzvf`解压、 `-C`指定目录 |

## 示例

```bash
tar -zxvf /home/myhome.tar.gz -C /opt/temp2  #将myhome.tar.gz解压到指定路径


tar -czvf backup.tar.gz 目录      # c=创建(打包), z=gzip压缩, v=显示过程, f=文件名
tar -tzvf backup.tar.gz           # t=查看归档里有什么（不解压）
tar -xzvf backup.tar.gz           # x=解压
```

## 笔记

插入命令用$()

```bash
tar -czvf lab-backup-$(date +%F).tar.gz lab    # 打包并压缩 lab 目录，带时间命名
```
