# 查找指令

## 常用命令

| 常用命令  | 说明                             | 常用参数                                            |
| --------- | -------------------------------- | --------------------------------------------------- |
| `cat`     | 浏览文件内容                     | `-n`显示行号、`\| more`按页显示文本                 |
| `more`    | 按页查看文件内容                 | 空格翻一页，回车翻一行，`q`离开more                 |
| `less`    | 分屏查看文件内容                 | 空格向下翻一页<br/>`/字串`向下搜索字串：n向下 N向上 |
| `echo`    | 输出内容到控制台                 |                                                     |
| `head`    | 显示文件开头部分内容，默认前十行 | `-n 数字`显示前数字行                               |
| `tail`    | 显示文件尾部内容，默认后十行     | `-n 数字`显示后数字行内容；`-f`实时追踪文档的更新   |
| `>`和`>>` | `>`：覆盖；`>>`：追加            |                                                     |
| `find`    | 指定范围搜索文件                 |                                                     |
| `locate`  | 快速定位文件路径                 | 首次执行前updatedb                                  |
| `grep`    | 过滤查找                         | `-n`显示行号、`-i`忽略大小写                        |

## 示例

```bash
find [搜索范围] 【参数】
-name    #指定文件名查找
-user    #查找属于指定用户文件
-size    #按文件大小查找(+n大于 -n小于 n等于) 
```
