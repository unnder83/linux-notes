# 文件与目录操作

## 常用命令

| 命令      | 说明                  | 常用参数                                |
| --------- | --------------------- | --------------------------------------- |
| `ls`      | 列出目录内容          | `-l` 详情、`-a` 含隐藏、`-h` 可读大小   |
| `cd`      | 切换目录              | `cd ..` 回到上一级目录、`cd ~` 回家目录 |
| `pwd`     | 显示当前路径          |                                         |
| `mkdir`   | 创建目录              | `-p` 递归创建                           |
| `cp`      | 复制                  | `-r` 递归、`-i` 覆盖前询问              |
| `mv`      | 移动/重命名           |                                         |
| `rm`      | 删除                  | `-r` 递归、`-f` 强制（慎用）            |
| `touch`   | 创建空文件/更新时间戳 |                                         |
| `find`    | 查找文件              | `find . -name "*.log"`                  |
| `tree`    | 树形显示目录          | `-L 2` 限制层级                         |
| `cal`     | 显示当前日历信息      |                                         |
| `ln`      | 连接,默认硬链接       | `-s`创建软连接                          |
| `history` | 查看历史命令          |                                         |
| `date`    | 显示当前日期          |                                         |

## 示例

```bash
ls -lah                    # 列出所有文件含隐藏，人类可读大小
mkdir -p notes/{a,b,c}     # 一次性创建多个嵌套目录
cp -ri src/ backup/        # 递归复制并询问覆盖
find /var/log -name "*.log" -mtime -7   # 找 7 天内修改过的日志
```
