# 进程查看与控制

## 常用命令

### `ps`

```bash
ps aux | head            # BSD 风格，USER/PID/%CPU/%MEM/命令
ps -ef | head            # System V 风格，多 PPID(父进程) 列
ps -p $$                 # 看当前 shell 自己的 PID（$$ 是当前 shell）

pstree                    # 显示进程树
pstree -p                 # 带 PID 显示进程树
pstree -u                 # 带 用户 显示进程树
```

### `kill`

```bash
kill [选项] [进程号]       # 用 pid 结束进程
killall [进程名]          # 结束进程包括其子进程
kill -TERM %1            # 发优雅退出信号（%1 = 第 1 个后台任务、用jobs查看）
kill -15 $PID            # 发优雅退出信号
kill -9 $PID             # 强制杀死
```

### `systemctl`

| systemctl子命令 | 作用                 | 例子                           |
| --------------- | -------------------- | ------------------------------ |
| `status`        | 看服务状态、最近日志 | `systemctl status nginx`       |
| `start`         | 启动服务             | `sudo systemctl start nginx`   |
| `stop`          | 停止服务             | `sudo systemctl stop nginx`    |
| `restart`       | 重启服务             | `sudo systemctl restart nginx` |
| `reload`        | 重载配置，不中断服务 | `sudo systemctl reload nginx`  |
| `enable`        | 设置开机自启         | `sudo systemctl enable nginx`  |
| `disable`       | 取消开机自启         | `sudo systemctl disable nginx` |

**restart vs reload 的区别**：`restart` 会短暂中断服务（连接断开），`reload` 只是让进程重新读配置、**不中断**。生产环境改完配置能用 reload 就别 restart。

### `top&htop`

```bash
top                      # 按 q 退出，按 P 按 CPU 排序，按 M 按内存排序
htop                     # 若没装: sudo apt install -y htop（彩色、更好用）
```

`top`页面，输入“u”回车，在输入用户名即可监控某用户；

输入“k”回车，在输入进程号即可结束进程。

### `journalctl`

```batch
journalctl -u nginx -f         # 看服务的日志
journalctl -xe                 # 最近系统日志（-e 跳到末尾，-x 带解释）
journalctl -u ssh -n 20        # ssh 服务最近 20 行日志
journalctl -u cron -f          # 实时跟踪 cron 日志（Ctrl+C 退出）
```

### `firewall`

```bash
打开端口：       firewall-cmd --permanent --add-port=端口号/协议
关闭端口：       firewall-cmd --permanent --remove-port=端口号/协议
重新载入：       firewall-cmd --reload
查询端口是否开放：firewall-cmd --query-port=端口号/协议
```

### `netstat`

```bash
netstat -anp    # 可查看协议
```

## 快捷键

- `Ctrl+C` 终止前台进程
- `Ctrl+Z` 挂起前台进程到后台
- `Ctrl+D` 发送 EOF，退出 shell

## 坑点：

- ⚠️ **别上来就 `kill -9`**：先`kill -15M 给进程清理机会，`kill -9` 是最后手段，否则可能损坏数据/残留锁文件
- ⚠️ **kill 之前先 `ps` 确认 PID**：PID 是复用的，杀错 PID = 事故
- ⚠️ **服务起不来先看 `journalctl -xe` + `systemctl status`**，别盲目重启三连
- ⚠️ SSH 连着服务器时，**别 `systemctl restart ssh`**——你会把自己的连接一起断掉
- ⚠️ 僵尸进程（`defunct`）：子进程死了但父进程没"收尸"，会累积占 PID
