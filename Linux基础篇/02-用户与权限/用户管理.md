# 用户管理

## 常用命令

| 命令                       | 说明                                   |
| -------------------------- | -------------------------------------- |
| `useradd`                  | 创建用户，`-m` 同时创建家目录          |
| `passwd`                   | 设置/修改密码                          |
| `usermod`                  | 修改用户，`-aG` 追加附加组，`-g`修改组 |
| `userdel`                  | 删除用户，`-r` 同时删除家目录          |
| `groupadd`                 | 创建用户组                             |
| `groupdel`                 | 删除用户组                             |
| `useradd -g 用户组 用户名` | 创建时指定组                           |
| `id`                       | 查看用户 UID/GID 和所属组              |
| `whoami`                   | 当前用户                               |
