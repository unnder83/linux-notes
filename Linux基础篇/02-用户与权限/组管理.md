# 组管理

## 常用命令

| 命令       | 说明               | 常用参数                        |
| ---------- | ------------------ | ------------------------------- |
| `chown`    | 修改文件所有者     |                                 |
| `groupadd` | 创建组             |                                 |
| `useradd`  | 创建用户           | `-g`创建用户时指定组            |
| `chgrp`    | 修改文件、目录属组 |                                 |
| `usermod`  | 改变用户所在组     | `-aG`追加到附加组、`-g`指定主组 |

## 示例

```bash
chown 用户名 文件名
chown tom apple.txt  #将apple.txt所有者变为tom
groupadd cat
useradd -g cat tom    #建立新用户并且放到cat组
passwd tom
```
