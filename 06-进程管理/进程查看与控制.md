# 进程查看与控制

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `ps aux` | 查看所有进程快照 |
| `top` / `htop` | 实时监控（htop 更友好） |
| `kill PID` | 终止进程，`-9` 强制终止 |
| `pkill name` | 按名称终止进程 |
| `jobs` / `bg` / `fg` | 管理后台任务 |
| `nohup cmd &` | 后台运行且退出终端不挂断 |

## 快捷键

- `Ctrl+C` 终止前台进程
- `Ctrl+Z` 挂起前台进程到后台
- `Ctrl+D` 发送 EOF，退出 shell

## 示例

```bash
ps aux | grep nginx        # 查找 nginx 进程
kill -9 12345              # 强制杀死 PID 12345
nohup python app.py > app.log 2>&1 &
```
