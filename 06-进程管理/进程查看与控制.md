## 快捷键

- `Ctrl+C` 终止前台进程
- `Ctrl+Z` 挂起前台进程到后台
- `Ctrl+D` 发送 EOF，退出 shell

## 示例

```bash
ps aux | grep nginx        # 查找 nginx 进程
kill -9 12345              # 强制杀死 PID 12345
nohup python app.py > app.log 2>&1 &
```
